# Jorge Truck Driver — Android Normal

Versão **Android com gráficos originais**, separada da Pixel Art.

## Instalação

Abra [Releases](../../releases) e baixe o APK publicado após uma compilação bem-sucedida. Também é possível acessar [Actions](../../actions) e baixar o artefato da compilação.

O jogo usa uma WebView com arquivo HTML local e controles de gamepad Android. A instalação precisa ser testada no dispositivo.

**Versões separadas:** [HTML Normal](https://github.com/alan102168/jogo-sest-senat-2d-caminhao) · [HTML Pixel](https://github.com/alan102168/jorge-html-pixel) · [Android Pixel](https://github.com/alan102168/jorge-truck-driver-android) · [Mega Drive Pixel](https://github.com/alan102168/jorge-megadrive-pixel).
